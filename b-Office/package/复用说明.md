# HistoryMinerva 发布与复用说明

`package/` 保存可重复执行的发布合同；版本化正式结果位于根目录 `z-HistoryMinerva`（清单与运行产物
同处），不能从部署槽或历史归档反推。

## 入口

- [NuGet 发布说明](./NuGet发布说明.md)：可复用程序集边界和远端推送门禁。
- [AppShell / OHS 模块发布说明](./OHS模块发布说明.md)：AppShell 3.1.9 正式发布、双槽部署、旧槽退役和回滚。

## 消费顺序

1. 读取根 `project.manifest.json` 与 `../current/项目概览.md`。
2. 实现变更读取 `../current/技术合同.md`，测试变更读取 `../current/验证合同.md`。
3. 修改版本只编辑 `../../b-Code-HistoryMinerva/build/HistoryMinerva.Version.props`。
4. AppShell 发布只执行受控脚本；NuGet 推送仍需要单独明确授权。

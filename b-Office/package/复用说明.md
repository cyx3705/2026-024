# SE2SW 发布与复用说明

`package/` 保存可重复执行的发布合同，不保存某次版本发布结果。历史发布收口记录直接保存在
`../history/`，当前项目状态和需求位于 `../current/`。

## 入口

- [NuGet 发布说明](./NuGet发布说明.md)：可打包边界、准备条件和发布门禁。
- [OHS 模块发布说明](./OHS模块发布说明.md)：模块清单、正式槽同步、核验和回退。

## 消费顺序

1. 先读取根目录 `project.manifest.json` 和 `../current/项目概览.md`。
2. 修改生产实现时读取 `../current/技术合同.md`。
3. 修改测试或门禁时读取 `../../b-Code-SE2SW-Tests/README.md` 和 `../current/验证合同.md`。
4. 涉及包版本、OHS 入槽或 NuGet 时读取本目录对应发布说明。

发布物只能从受控源码和唯一版本源生成，不能从历史归档、正式槽或本机缓存反推。

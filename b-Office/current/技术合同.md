# HistoryMinerva 4.2.3 技术合同

`history/` 保存版本化计划与迁移前事实。本文件是 HistoryMinerva 当前实现和验收的唯一技术真值。

## REQ-001 对外身份与兼容边界

- 模块名、部署槽、数据目录和命令域统一为 `HistoryMinerva`，全部取自
  `HistoryMinerva.Contracts` 的 `HistoryMinervaIdentity` 唯一权威源；代码不得出现独立名称字面量。
- 停靠页标题为短形 `Minerva`，窗口内部标识 `historyminerva`；版本由
  `b-Code-HistoryMinerva/build/HistoryMinerva.Version.props` 唯一决定。
- 当前源码、候选合同与正式 `z-HistoryMinerva` 版本均为 `4.2.3`。行为不同时不得复用同一
  版本号，也不得用当前源码文档覆盖解释发布历史中的旧正式包。
- `HistoryMinerva.convert`、`HistoryMinerva.cancel` 是前端写命令，要求 UI 线程，`Readonly=false`、
  `AllowMcpExecution=false`；服务端前端代理负责跨进程转发，MCP 不出现这两个命令。
- `HistoryMinerva.show/hide/status` 是 SWuse 窗口移除后的占位指令，如实说明现状并报告 Worker 状态。
- 宿主命令表忽略大小写；`mapping.*`、`swuse.*` 旧指令域已作废，无兼容别名。
- 内部程序集与命名空间统一为 `HistoryMinerva.*`/`SWuse.*`；Worker JSON 请求/事件/结果协议、COM 调用和
  输出目录规则不变，且不保留旧转换模块命名兼容层。

## REQ-002 通用两栏 UI

- 页面根使用透明背景，宿主决定外层 Canvas；页面使用 `Shell.Brush.*`、`Shell.Font.*`、`Shell.Space.*`、
  `Shell.Radius.*`、`Shell.Size.*` 动态令牌，不在生产 XAML 固定颜色、字体或第二套控件模板。
- 顶部为两个等宽栏：转换来源、转换内容。转换内容只有 `.par → .SLDPRT` 和 `.asm → .SLDASM`。
- 顶部每个等宽栏内，标签与来源/内容选择控件同处一行；正文和表头使用宿主正文层级，保持 13px 可读密度。
- 零件列表直接从表头开始，不保留独立的“零件”标题行；底部转换选项、状态和主按钮组成一条紧凑操作栏，窄窗口允许按视觉顺序换行。
- Minerva 页是 `DockSide.Center` 单例中央业务页，页面不创建自己的窗口标题、停靠区或窗口按钮。
- 320px、浅色/深色和 100%/125%/150% DPI 下，来源选择、内容选择、选项和主操作保持可见可操作；长路径和映射名以省略号或换行处理。

## REQ-003 宿主上下文与数据

- UI 模块和命令类实现 `IModuleContextAware`，使用宿主 `CommandBus`、`IShellLog`、设置和数据根。
- `MappingRuntimePaths` 从 `IModuleContext.DataDirectory` 与 `module.dir` 推导模块数据目录、双槽路径、请求和探查目录。
- Worker 定位顺序为当前程序集目录、宿主进程基目录、`module.dir/HistoryMinerva` 部署槽，最后回退到宿主所在 HistoryVesta 根下的 `z-HistoryMinerva` 正式包；找不到时返回首候选供预检报告。
- 源 CAD 文件只读；扫描、探查和纯内存规划不创建 XT/SW 输出目录，环境检查通过后才创建。

## REQ-004 单一 Worker 与 CAD 生命周期

- 所有 COM 工作由单一 `HistoryMinerva.Worker.exe`（x64 STA）完成；入口按参数形态路由：
  HistoryMinerva 转换 `<verb> <json> --cancel <signal>`（4 参数），SWuse 构建 `--request <json>`（2 参数）。
- Solid Edge `SaveBody` 输出 Parasolid `.x_t`，SolidWorks 导入并保存 `.SLDPRT/.SLDASM`；装配层级、矩阵、特征守卫和配合回滚沿用既有 3.6.7 真机合同。
- SWuse 建模链（Roslyn dry-run 编译 + `SWuse.Api` + SolidWorks 零件构建）保留在协议层，无独立 UI。
- UI 不持有 CAD COM 对象；取消和卸载必须等待 Worker 收束，不终止宿主已有 CAD 会话。

## 依赖与发布

- .NET 8、Windows Desktop Runtime、Solid Edge 2020 COM、SolidWorks 2025 SP5 COM、FeatureWorks。
- HistoryVulcan 3.4.0 正式消费快照为 `../2026-023-HistoryVulcan/z-HistoryVulcan`；宿主 manifest 与
  HistoryVulcan.Core 的 SHA256 钉定值以 `HistoryMinerva.Version.props` 为唯一真源（随宿主包重生成重钉），
  文档不复制哈希副本。
- `z-HistoryMinerva` 是唯一正式消费目录（清单与运行产物同处）；候选只由 `Build-HistoryMinervaPackage.ps1`
  从 Release 输出生成，正式提升和文档镜像由 Diana 集中事务控制，备份必须位于 Modules 目录之外。

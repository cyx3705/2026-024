# Mapping 技术合同

本文是 Mapping `4.0.0` 的现行需求与架构真值。`history/` 中的版本设计、COM 研究和验收记录
只保留当时事实，不作为当前行为依据。

## 现行需求

### REQ-001 通用映射界面

- 顶部固定为两个等宽栏：`转换来源` 与 `转换内容`；不再显示 XT 或 SW 输出目录栏。
- 转换内容当前只有两项：Solid Edge `.par` → SolidWorks `.SLDPRT`，以及 Solid Edge `.asm` →
  SolidWorks `.SLDASM`。
- `.par` 映射选择包含顶层 `.par` 的文件夹，显示全宽零件表；`.asm` 映射选择单个装配文件，选择后
  只读探查并显示装配树与零件表。
- 切换转换内容或来源必须清除上一来源的计划、结果和状态；不创建输出目录。

### REQ-002 路径与转换边界

- 内部管线仍使用来源目录下的 `XT/` 与 `SW/` 默认输出规则；XT 是管线细节，不向 UI 用户配置。
- Worker 通过 Solid Edge `SaveBody` 输出文本 Parasolid `.x_t`，再由 SolidWorks 导入并保存为
  `.SLDPRT/.SLDASM`；源 `.par/.asm` 保持只读。
- 扫描、来源切换、装配探查和纯内存重规划不得创建输出目录；环境检查通过后才创建。
- 输出复用必须通过既有安全判定，禁止静默覆盖未知文件；失败项返回结构化原因。

### REQ-003 装配、识别与关系

- 每个唯一子装配生成独立 `.SLDASM`，父装配按源层级引用；局部与世界矩阵互验阈值为 `1e-9`，输出
  位置偏差不得超过 `1e-6 m`。
- FeatureWorks 识别必须通过体积相对偏差 `2e-5`、残留导入体和特征树语义守卫；失败、超时或不匹配时
  从原 XT 安全降级为几何完整的哑实体。
- 配合只翻译已实测的平面、轴和接地关系；逐条验证位置，超差则回滚并恢复组件姿态。

### REQ-004 OHS 集成

- OHS 模块名为 `Mapping`，模块/窗口 ID 和命令域为 `mapping`，窗口标题为 `Mapping`，版本来自
  `b-Code-SE2SW/build/SE2SW.Version.props`，当前为 `4.0.0`。
- 清单保持 `name=Mapping`、`ui=true`、`mcpExposure=readonly`。命令行和 MCP 只暴露安全查询：
  `mapping.show`、`hide`、`status`、`paths`、`scan`、`assemblyPaths`、`assemblyProbe`；不暴露真实 CAD
  转换。
- 这是破坏性更名：旧 `se2sw.*` 命令、`SE2SW` 模块槽和窗口 ID 不保留兼容别名。内部程序集、Worker、
  JSON 协议和部署产物名称仍为 SE2SW。

## 质量属性

| 编号 | 属性 | 要求 | 验收 |
| --- | --- | --- | --- |
| QA-001 | 源文件安全 | `.par/.asm` SHA-256 前后不变 | 真实 CAD 门禁 |
| QA-002 | 几何安全 | 识别体积相对偏差不超过 `2e-5` | 几何门禁 |
| QA-003 | 装配精度 | 最大平移偏差不超过 `1e-6 m` | 装配门禁 |
| QA-004 | 生命周期 | 不遗留自有进程，不终止既有用户会话 | 进程前后快照 |
| QA-005 | 可重复构建 | Release 0 警告、0 错误，Smoke PASS | build/test 命令 |
| QA-006 | UI 收敛 | 两个等宽顶栏、两项映射、无输出目录控件 | UI Smoke 截图与断言 |

## 系统架构

| 组件 | 路径 | 职责 |
| --- | --- | --- |
| Mapping UI 模块 | `b-Code-SE2SW/src/SE2SW` | 来源、映射选择、计划、进度、取消和 OHS 集成 |
| Contracts | `b-Code-SE2SW/src/SE2SW.Contracts` | JSON 协议、路径和几何匹配纯逻辑 |
| Worker | `b-Code-SE2SW/src/SE2SW.Worker` | x64 STA COM 自动化和输出落盘 |
| Smoke | `b-Code-SE2SW-Tests/tests/SE2SW.Smoke` | 不启动 CAD 的回归 |
| CAD 门禁 | `b-Code-SE2SW-Tests/tools` | 真机几何、装配、关系和生命周期验收 |

权威版本源是 `b-Code-SE2SW/build/SE2SW.Version.props`；`z-SE2SW/module.manifest.json` 是 OHS
消费的注册元数据。`bin/obj`、CAD 临时输出和正式模块槽不是权威源。

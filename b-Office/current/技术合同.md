# SE2SW 技术合同

本文是 3.6.7 现行需求与架构真值。历史记录位于 `../history/SE2SW`，与本文、源码或测试冲突时
不作为现行行为依据。

## 现行需求

### REQ-001 来源与路径

- 用户选择单个 `.asm` 或包含顶层 `.par` 的文件夹；装配立即只读探查，文件夹不递归扫描。
- 外界模式输出固定为源目录下的 `XT/` 与 `SW/`；探查阶段不得创建目录。
- 取消选择不改变有效来源，来源切换必须清除上一来源的计划和状态。

### REQ-002 零件转换

- Worker 通过 Solid Edge `SaveBody` 输出文本 Parasolid `.x_t`，并校验格式、稳定性和源文件哈希。
- SolidWorks 从 XT 导入并保存 `.SLDPRT`；输出按复用合同判定，禁止静默覆盖未知文件。
- 源 `.par` 保持只读，失败项可重试且必须带结构化原因。

### REQ-003 嵌套装配

- 每个唯一子装配生成独立 `.SLDASM`，父装配按源层级引用；局部矩阵由对应 `.asm` 直接读取。
- 世界矩阵与局部矩阵互验阈值为 `1e-9`，装配输出位置偏差不得超过 `1e-6 m`。
- 缺失零件只跳过对应组件；不能安全复用的空、过期或需重建产物必须重做。

### REQ-004 FeatureWorks 识别

- 每个唯一零件在隔离子 Worker 中处理，普通零件识别掩码固定为机械特征六位 `0x3F`。
- 识别必须通过体积相对偏差 `2e-5`、残留导入体和特征树语义守卫。
- 识别失败、超时、会话崩溃或语义不匹配时，从原 XT 重建几何完整的哑实体并报告。
- 识别依赖已人工激活 FeatureWorks 的 SolidWorks 进程，模块不得卸载加载项破坏该激活态。

### REQ-005 装配关系重建

- 仅翻译已实测的平面、轴和接地关系，未知类型必须报告而不是猜测。
- 每条配合建立后立即验证位置；偏差超限时删除配合并恢复组件姿态。
- 未被有效配合约束的组件保持固定，位置精度优先于配合数量。

### REQ-006 OHS 集成

- 模块 ID 为 `se2sw`，版本来自 `build/SE2SW.Version.props`，当前为 3.6.7。
- OHS 清单保持 `name=SE2SW`、`ui=true`、`mcpExposure=hidden`，转换只从本机 UI 触发。
- 装配 Worker 无进度预算为 20 分钟，零件为 180 秒；任何 Worker 事件都刷新隔离层时钟。

## 质量属性

| 编号 | 属性 | 要求 | 验收 |
| --- | --- | --- | --- |
| QA-001 | 源文件安全 | `.par/.asm` SHA-256 前后不变 | 真实 CAD 门禁 |
| QA-002 | 几何安全 | 识别体积相对偏差不超过 `2e-5` | 几何门禁 |
| QA-003 | 装配精度 | 最大平移偏差不超过 `1e-6 m` | 装配门禁 |
| QA-004 | 生命周期 | 不遗留自有进程，不终止既有用户会话 | 进程前后快照 |
| QA-005 | 可重复构建 | Release 0 警告、0 错误，Smoke PASS | build/test 命令 |

## 系统架构

| 组件 | 路径 | 职责 |
| --- | --- | --- |
| UI 模块 | `b-Code-SE2SW/src/SE2SW` | 来源、计划、进度、取消和 OHS 集成 |
| Contracts | `b-Code-SE2SW/src/SE2SW.Contracts` | JSON 协议、路径和几何匹配纯逻辑 |
| Worker | `b-Code-SE2SW/src/SE2SW.Worker` | x64 STA COM 自动化和输出落盘 |
| Smoke | `b-Code-SE2SW/tests/SE2SW.Smoke` | 不启动 CAD 的回归 |
| CAD 门禁 | `b-Code-SE2SW/tools` | 真机几何、装配、关系和生命周期验收 |

UI 只读探查并生成请求，独立 Worker 导出 XT、导入或识别零件、按层构建装配，随后回传结构化事件并
收束自身 COM 对象和进程。UI、OHS 宿主与 Worker 之间不传递 COM 引用。

权威版本源是 `b-Code-SE2SW/build/SE2SW.Version.props`；`z-SE2SW/module.manifest.json` 是供 OHS 消费的
注册元数据。`bin/obj` 和 CAD 临时输出不是权威源。

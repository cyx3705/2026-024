# HistoryMinerva 现行约定

本仓唯一的长期文档。这里只写**从代码和测试里看不出来的取舍**；做法以代码为准，CAD COM 的坑点写在调用处的注释里，
每版做了什么看 `git log`。条目被推翻就直接改掉，不留历史。

## 真相在哪

| 要知道的 | 去哪看 |
| --- | --- |
| `minerva.*` 指令怎么调用 | 注册自描述：`diana.docs.read domain=minerva`；跨模块与 AI 优先用无状态的 `minerva.plan.*` |
| 代码面（`HistoryMinerva.Contracts.dll`） | 随包的 `HistoryMinerva.Contracts.xml`，IDE 里直接可见；公开类型缺 summary 由 Smoke 拦 |

| 版本与宿主下限 | `b-Code-HistoryMinerva/build/HistoryMinerva.Version.props`（唯一版本源） |

## 产品取舍

- **几何正确优先于特征树。** 识别或配合重建过不了守卫时，退回几何完整、位置正确的结果并如实报降级；错的特征树、漂了的装配比可见的降级更危险。
- **识别结果按「人工还能不能救」取舍。** 残留导入体一律丢弃（人工修不回来）；特征完备但类型、尺寸不完美的一律放行（人工能改）。不设体积 / 面数几何守卫。
- **源文件只读，产物绝不是源文件本身。** 计划器与 Worker 校验器各拦一次。转换只在副本上进行。
- **一条规则只有一条管线。** 删图号就是前缀为空的那一次写入；既有图号一律按文件名第一个空格切，不校验旧号长什么样。
- **用户看到的是事实，不是猜测。** 外购件品牌查不到写 `N/A`、不许猜；找不到工程图在表里写「无」；读不到的属性留空，不把探查拖成失败。
- **采购交付不陪 CAD 一起失败。** 两张 BOM 由前端按嵌入的模板写，不经 Worker、不驱动 Excel、不引入表格库。
- **控制栏只说开头、结尾和失败。** 逐个文件的成功只更新表格那一行；失败的最终消息必须带 Worker 报回的第一条原因。
- **选来源只写路径。** 不解析装配体、不在 UI 线程探测文件；选错类型时说明原因并保持原来源，命令仍成功（失败指令会让宿主抢控制台、整窗卡死）。

## 真机才知道的

- **FeatureWorks 的自动识别依赖进程内激活态**：该 SolidWorks 进程里必须先人工做过一次特征识别，否则整批只会产出压平后的导入体（几何与装配位置不受影响）。激活态不跨进程、退出不保留，因此特征整备无法真正无人值守，界面与批次收尾都要明说。
- 约 30% 的零件本就识别不出特征，这是预期质量，不是缺陷。
- 带真实配合的 SolidWorks 装配样件尚未取得，SW 源的配合重建只有离线契约测试覆盖。
- 整体打包的 `SaveAs3` 导出（STEP / DWG / PDF）没有自动化门禁，靠真机手工：选含工程图的样件总装 → 解析 → 打包，核对 `图纸/` 三件套、多页 PDF 页数齐全、两张 BOM 与表格行数一致、外购装配体只占一行、源文件 SHA256 不变。
- 云端 CI 不启动任何 CAD；`VERIFY-SW-SELF`（`SolidWorksSelfPipelineGate`）与 Solid Edge 门禁只在有授权、桌面会话与样件的机器上人工触发。

## 已知缺口

- **G-4**：`RenameReindex.Remap` 不搬 `PurchasedParts`——同一份探查结果先改名再算打包，外购件整批消失。
- **G-6**：没有事件订阅，消费方拿不到逐条 `WorkerEvent`，只能读日志文本。

## 工程约定

- 发版改三处版本号：`HistoryMinerva.Version.props`、`b-Code-HistoryMinerva/module.manifest.json`、`project.manifest.json`；质量门禁核对它们一致。
- 所有 COM 工作在单一 `HistoryMinerva.Worker.exe`（x64 STA）里；UI 不持有 CAD COM 对象，取消与卸载要等 Worker 收束，不终止用户已有的 CAD 会话。
- `module.manifest.json` 的 deps 只列托管程序集（`HistoryMinerva.Contracts.dll`）；Worker.exe / json 写进去会被宿主当成坏 IL 整个跳过。
- 请求 JSON 的新字段只能追加在记录**末尾**并给缺省值，旧请求必须仍能执行；枚举按数值序列化，新值只能追加。
- 三个工程零 NuGet 依赖；锁定还原、离线构建与候选包边界都建立在这一点上。BOM 模板 `.xlsx` 显式退出 LFS。
- `tools/` 只保留三个可重复执行的 CAD 端到端门禁；一次性探针用完即删，结论进代码注释或 Smoke。
- 施工方案、实测报告、问题单不留存：做完即删，仍有效的结论写进本文或代码注释。

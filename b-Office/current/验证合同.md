# SE2SW 验证合同

## 验证层级

| 编号 | 命令或步骤 | 通过标准 |
| --- | --- | --- |
| VERIFY-CONTRACT | `powershell -NoProfile -ExecutionPolicy Bypass -File .\b-Code\Test-ProjectContract.ps1 -Instantiation` | manifest、路径、链接、目录和占位符检查通过 |
| VERIFY-BUILD | `dotnet build .\b-Code-SE2SW\src\SE2SW\SE2SW.csproj -c Release -p:NuGetAudit=false` | 0 警告、0 错误 |
| VERIFY-SMOKE | `dotnet run --project .\b-Code-SE2SW-Tests\tests\SE2SW.Smoke\SE2SW.Smoke.csproj -c Release -p:NuGetAudit=false` | 输出 `SE2SW.Smoke: PASS` |
| VERIFY-UI | `dotnet run --project .\b-Code-SE2SW-Tests\tests\SE2SW.UiSmoke\SE2SW.UiSmoke.csproj -c Release -p:NuGetAudit=false -- --capture <png>`，并追加 `--compact`、`--busy` 变体 | 无重复标题/底部运行区，路径条尺寸稳定且运行条状态正确 |
| VERIFY-FORMAT | `dotnet format .\b-Code-SE2SW\src\SE2SW\SE2SW.csproj --verify-no-changes --no-restore` | 无格式差异 |
| VERIFY-CAD | 使用 `b-Code-SE2SW-Tests/tools` 中对应门禁和专用样件 | 几何、装配、哈希与生命周期满足技术合同 |
| VERIFY-DEPLOY | OHS `tool.scan`、`tool.sync name=SE2SW`、`tool.list`、`module.list` | 唯一来源、3.8.0、7/7 哈希一致、模块装载 |

## 真实 CAD 前提

- Windows x64，已安装并注册 Solid Edge 2020 和 SolidWorks 2025 SP5。
- 使用复制到临时目录的专用样件，不直接在原始工程上执行门禁。
- FeatureWorks 档要求已人工激活的 SolidWorks 会话，运行前关闭未保存的同名文档。
- 门禁启动前记录已有 CAD 进程，结束后只核对和回收本次明确创建的进程。

## 验收重点

- 源 CAD 文件 SHA-256 不变。
- 零件识别满足 `2e-5` 体积相对偏差和语义守卫，否则安全降级。
- 装配最大位置偏差不超过 `1e-6 m`，局部/世界矩阵自检不超过 `1e-9`。
- Worker 和自有 CAD 进程收束，不影响启动前已有用户会话。
- 正式槽产物、清单版本与源 Release 输出一致。

迁移、纯文档或项目治理改动不重复运行真实 CAD 门禁，但必须保留对应版本的最近真机证据，并完成合同、
Release 构建、Smoke 和 OHS 装载核验。

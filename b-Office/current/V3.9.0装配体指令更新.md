# SE2SW V3.9.0 装配体指令更新

## 目标

补齐 3.8.0 指令总线中缺失的装配体模式入口，使 AppShell 命令行和只读 MCP 可以解析装配输出路径，并调用现有隔离 Worker 获取结构化装配探查结果。

## 新增指令

| 指令 | 参数 | 行为 |
| --- | --- | --- |
| `se2sw.assemblyPaths` | `source`、可选 `xt`、可选 `sw` | 解析 `.asm` 对应的 `.SLDASM`、XT 和 SW 目录，不启动 CAD、不创建目录 |
| `se2sw.assemblyProbe` | `source`、可选 `xt`、可选 `sw` | 通过现有装配探查 Worker 只读解析 `.asm`，返回层级、零件、关系、阻塞问题和计划输出 |

`assemblyProbe` 返回以下结构化状态：是否可转换、实例数、零件数、已有产物数、抑制/未解析数、子装配数、最大深度、关系数、零件输出计划、装配节点、阻塞问题和警告。

## 安全边界

- 两条命令均不执行 CAD 转换，不创建 XT、SLDPRT 或 SLDASM 产物。
- `assemblyProbe` 会只读启动 Solid Edge 探查 Worker，并清理请求和结果临时文件。
- 真实装配转换、FeatureWorks 和配合重建仍只从本机 UI 触发。
- Worker JSON 协议、COM 行为、窗口 ID 和输出目录规则保持不变。

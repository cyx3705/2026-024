# Mapping 项目概览

更新日期：2026-08-06

## 一句话定义

Mapping 是本机受控文件映射模块，当前提供 Solid Edge 零件和装配体到 SolidWorks 的转换能力，
交付为 OneHistoryStudio / AppShell UI 模块与独立 CAD COM Worker。

## 当前范围

- UI 以转换来源和转换内容为唯一顶层设置，现支持 `.par → .SLDPRT` 与 `.asm → .SLDASM`。
- 内部保留成熟的 SE2SW 转换、Worker、JSON 协议和 XT/SW 默认输出管线。
- 命令域和 MCP 为 `mapping`，仅公开只读查询；真实转换只能由用户在本机 UI 明确触发。
- 不转换 `.psm`、`.dft`，不提供无人值守远程 CAD 服务，也不承诺所有 FeatureWorks 结果等价人工重建。

## 关键依赖

- Windows x64、.NET 8、OneHistory.AppShell.Core 3.0.3。
- Solid Edge 2020 COM、SolidWorks 2025 SP5 COM 和 FeatureWorks。
- 通过 COM 注册和运行时探测定位厂商组件；不硬编码安装目录。
- 源 CAD 只读，不关闭启动前已有的用户 CAD 进程。

# Mapping 项目概览

更新日期：2026-08-08

## 一句话定义

Mapping 是独立维护的 AppShell 文件映射模块，提供 Solid Edge 零件和装配体到 SolidWorks 的受控转换，
UI 与独立 x64 CAD COM Worker 共享稳定的 SE2SW 内部协议。

## 当前范围

- 对外模块、窗口、命令域和 MCP 名称为 `Mapping` / `mapping`，版本 `4.1.0`。
- UI 只配置转换来源和转换内容：`.par → .SLDPRT`、`.asm → .SLDASM`，两个顶栏等宽。
- `mapping.status/paths/scan/assemblyPaths/assemblyProbe/show/hide` 保持只读查询；`mapping.convert` 与
  `mapping.cancel` 只从 AppShell 前端执行，不投影到 MCP。
- 内部程序集、Worker、JSON 协议、XT/SW 默认输出和 COM 行为保持 SE2SW 约束；不运行真实 CAD 门禁。

## 主要交付物

| 交付物 | 权威位置 |
| --- | --- |
| 生产模块与 Worker | `b-Code-SE2SW/src` |
| 独立 Smoke、UI Smoke 与 CAD 门禁 | `b-Code-SE2SW-Tests` |
| AppShell 模块清单 | `z-SE2SW/module.manifest.json` |
| AppShell 正式快照 | `z-Package-Mapping` |
| 发布与部署脚本 | `b-Code-SE2SW/eng` |

## 宿主与数据

工程直接消费 `2026-023-AppShell/z-Package-AppShell` 3.1.9；`AppShell.Core.dll` 生产引用为
`Private=false`，模块包不得私带宿主 DLL。运行数据位于宿主数据根 `Mapping/`，Worker 请求和探查结果分别位于
`Mapping/requests` 与 `Mapping/probes`。正式模块部署到 AppShell 前端与服务端两个 `Mapping` 槽。

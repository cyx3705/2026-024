# HistoryMinerva 项目概览

更新日期：2026-08-18

## 一句话定义

HistoryMinerva 是注册到 HistoryVulcan 的单一 CAD 转换模块。当前源码线为 `4.4.3`：中央停靠页只做
四种转换（`.par → .SLDPRT`、`.asm → .SLDASM`、`.SLDASM → .SLDASM` 特征整备、`.SLDASM → 属性整备（改名）`），
由单一 `HistoryMinerva.Worker.exe` 执行。历史 SWuse C# 建模（Api / Roslyn / 双参数构建协议）已从源码、
包体与真机门禁删除。前身双模块合同见 `b-Office/history/42-V4.1.0-HistoryMinerva模块合并计划.md`。

## 当前范围

- 对外模块名为 `HistoryMinerva`、命令域为 `minerva`（唯一权威源 `HistoryMinervaIdentity`），源码版本 `4.4.3`；
  停靠页标题为短形 `Minerva`，窗口内部标识 `historyminerva`。
- UI 只配置转换来源和转换内容四项。选中属性整备时填写图号前缀并按所选装配体层级就地改名，
  或按文件名第一个空格洗掉图号。两个顶栏等宽。装配结构从左下角「打开」自左侧弹出，四种转换默认只显示零件表。
- SW 特征整备把源装配里的每个零件都先严格导出到 `XT/`，再对 XT 跑特征识别与草图完全定义，
  再按源层级重建装配。识别不可用时产物仍是压平后的导入体。设计与真机证据见
  `b-Office/history/45-V4.3.0-SW自整备转换管线.md`。
- `minerva.conversion.probe/run/strip/cancel` 只从 HistoryVulcan 前端执行，不投影到 MCP；
  `minerva.worker.show/hide/status/path/capabilities` 在后台权威表注册并作为只读 MCP 工具暴露。
- 页面探查、转换和取消只走命令总线；Worker 事件与最终结果进入 Vulcan 日志/控制台。
- 内部程序集与命名空间为 `HistoryMinerva.*`。Worker 只接受转换四参数协议。
  SW 自整备链路已跑过真机门禁；Solid Edge 链路未改动，沿用既有真机证据。

## 宿主与数据

工程直接消费 `2026-023-HistoryVulcan/z-Publish` 3.11.1；`HistoryVulcan.Core.dll` 生产引用为
`Private=false`，模块包不得私带宿主 DLL。运行数据位于宿主数据根 `HistoryMinerva/`，Worker 请求和
探查结果分别位于 `HistoryMinerva/requests` 与 `HistoryMinerva/probes`。正式模块部署到 HistoryVulcan 前端与
服务端两个 `HistoryMinerva` 槽。

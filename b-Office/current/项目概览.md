# HistoryMinerva 项目概览

更新日期：2026-08-11

## 一句话定义

HistoryMinerva 是注册到 HistoryVulcan 的单一 CAD 模块。当前源码线为 `4.3.0`：纯前端（原 Mapping 中央停靠页，
Solid Edge → SolidWorks 受控转换，以及 SolidWorks 装配体的特征整备）+ 纯后端（单一
`HistoryMinerva.Worker.exe`，内部路由映射转换与 SWuse 建模两类既有工作协议）。前身双模块（Mapping/SWuse）合同见
`b-Office/history/42-V4.1.0-HistoryMinerva模块合并计划.md` 与 `b-Office/history/swuse-v0.1/docs`。

## 当前范围

- 对外模块名与命令域统一为 `HistoryMinerva`（唯一权威源 `HistoryMinervaIdentity`），源码版本 `4.3.0`；
  停靠页标题为短形 `Minerva`，窗口内部标识 `historyminerva`。
- 正式 `z-HistoryMinerva` 仍是 `4.2.3`（无 SW 自整备管线的旧形态）；`4.3.0` 的正式提升需用户显式批准，
  由 Diana 集中发布事务完成。旧 `4.2.2` 三命令快照仅保留在发布历史中。
- UI 只配置转换来源和转换内容：`.par → .SLDPRT`、`.asm → .SLDASM`、`.SLDASM → .SLDASM`（SolidWorks
  特征整备），两个顶栏等宽。SW 自整备把源装配里没有特征的零件在**副本**上跑既有特征识别与草图完全定义，
  再按源层级重建装配；识别不可用时产物退回与源逐字节相同的零件副本。设计与真机证据见
  `b-Office/history/45-V4.3.0-SW自整备转换管线.md`。
- `HistoryMinerva.convert` 与 `HistoryMinerva.cancel` 只从 HistoryVulcan 前端执行，不投影到 MCP；
  `HistoryMinerva.show/hide/status` 为 SWuse 窗口移除后的只读占位指令。
- SWuse 独立窗口已删除（待打磨后回归）；其 C# 建模 API、Roslyn 编译与构建协议保留在后端。
- 内部程序集、Worker 路由、JSON 协议、XT/SW 默认输出和 COM 行为统一为 HistoryMinerva/SWuse 约束，
  不保留旧转换模块命名。SW 自整备链路已跑过真机门禁；Solid Edge 链路未改动，沿用既有真机证据。

## 宿主与数据

工程直接消费 `2026-023-HistoryVulcan/z-HistoryVulcan` 3.5.0；`HistoryVulcan.Core.dll` 生产引用为
`Private=false`，模块包不得私带宿主 DLL。运行数据位于宿主数据根 `HistoryMinerva/`，Worker 请求和
探查结果分别位于 `HistoryMinerva/requests` 与 `HistoryMinerva/probes`。正式模块部署到 HistoryVulcan 前端与
服务端两个 `HistoryMinerva` 槽；部署时退役全部旧 `Mapping`、`SWuse` 与历史转换模块槽。

# HistoryMinerva 项目概览

更新日期：2026-08-08

## 一句话定义

HistoryMinerva 是注册到 AppShell 的单一 CAD 模块（4.2.0）：纯前端（原 Mapping 中央停靠页，
Solid Edge → SolidWorks 受控转换）+ 纯后端（单一 `HistoryMinerva.Worker.exe`，内部路由
SE2SW 转换与 SWuse 建模两条既有协议）。前身双模块（Mapping/SWuse）合同见
`b-Office/history/42-V4.1.0-HistoryMinerva模块合并计划.md` 与 `b-Office/history/swuse-v0.1/docs`。

## 当前范围

- 对外模块、窗口、命令域和 MCP 名称为 `HistoryMinerva` / `historyminerva`，版本 `4.2.0`。
- UI 只配置转换来源和转换内容：`.par → .SLDPRT`、`.asm → .SLDASM`，两个顶栏等宽。
- `historyminerva.convert` 与 `historyminerva.cancel` 只从 AppShell 前端执行，不投影到 MCP；
  `historyminerva.show/hide/status` 为 SWuse 窗口移除后的只读占位指令。
- SWuse 独立窗口已删除（待打磨后回归）；其 C# 建模 API、Roslyn 编译与构建协议保留在后端。
- 内部程序集、Worker 路由、JSON 协议、XT/SW 默认输出和 COM 行为保持 SE2SW/SWuse 既有约束；
  不运行真实 CAD 门禁。

## 宿主与数据

工程直接消费 `2026-023-AppShell/z-Package-AppShell` 3.1.9；`AppShell.Core.dll` 生产引用为
`Private=false`，模块包不得私带宿主 DLL。运行数据位于宿主数据根 `HistoryMinerva/`，Worker 请求和
探查结果分别位于 `HistoryMinerva/requests` 与 `HistoryMinerva/probes`。正式模块部署到 AppShell 前端与
服务端两个 `HistoryMinerva` 槽；部署时退役全部旧 `Mapping`/`SWuse`/`SE2SW` 槽。

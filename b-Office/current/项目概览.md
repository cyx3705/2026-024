# HistoryMinerva 项目概览

更新日期：2026-08-10

## 一句话定义

HistoryMinerva 是注册到 HistoryVulcan 的单一 CAD 模块。当前源码与候选线为 `4.2.3`：纯前端（原 Mapping 中央停靠页，
Solid Edge → SolidWorks 受控转换）+ 纯后端（单一 `HistoryMinerva.Worker.exe`，内部路由
映射转换与 SWuse 建模两类既有工作协议）。前身双模块（Mapping/SWuse）合同见
`b-Office/history/42-V4.1.0-HistoryMinerva模块合并计划.md` 与 `b-Office/history/swuse-v0.1/docs`。

## 当前范围

- 对外模块名与命令域统一为 `HistoryMinerva`（唯一权威源 `HistoryMinervaIdentity`），源码版本 `4.2.3`；
  停靠页标题为短形 `Minerva`，窗口内部标识 `historyminerva`。
- 最新正式 `z-HistoryMinerva` 已通过 Diana 集中发布管线提升为 `4.2.3`；源码、候选、正式包与
  五命令、新 UI 消费合同现已对齐。旧 `4.2.2` 三命令快照仅保留在发布历史中。
- UI 只配置转换来源和转换内容：`.par → .SLDPRT`、`.asm → .SLDASM`，两个顶栏等宽。
- `HistoryMinerva.convert` 与 `HistoryMinerva.cancel` 只从 HistoryVulcan 前端执行，不投影到 MCP；
  `HistoryMinerva.show/hide/status` 为 SWuse 窗口移除后的只读占位指令。
- SWuse 独立窗口已删除（待打磨后回归）；其 C# 建模 API、Roslyn 编译与构建协议保留在后端。
- 内部程序集、Worker 路由、JSON 协议、XT/SW 默认输出和 COM 行为统一为 HistoryMinerva/SWuse 约束，
  不保留旧转换模块命名；不运行真实 CAD 门禁。

## 宿主与数据

工程直接消费 `2026-023-HistoryVulcan/z-HistoryVulcan` 3.4.0；`HistoryVulcan.Core.dll` 生产引用为
`Private=false`，模块包不得私带宿主 DLL。运行数据位于宿主数据根 `HistoryMinerva/`，Worker 请求和
探查结果分别位于 `HistoryMinerva/requests` 与 `HistoryMinerva/probes`。正式模块部署到 HistoryVulcan 前端与
服务端两个 `HistoryMinerva` 槽；部署时退役全部旧 `Mapping`、`SWuse` 与历史转换模块槽。

# SE2SW 项目概览

更新日期：2026-08-05

## 一句话定义

SE2SW 为本机 CAD 用户提供受控的 Solid Edge 零件和装配体到 SolidWorks 的批量转换能力，
交付形态为 OneHistoryStudio / AppShell UI 模块与独立 COM Worker。

## 目标与边界

- 稳定转换 `.par/.asm`，保留零件几何、装配层级和源姿态。
- 在不牺牲几何正确性的前提下提供可选特征识别和装配关系重建。
- 将 CAD 自动化隔离在独立进程，并保持源文件和用户 CAD 会话安全。
- 不转换 `.psm`、`.dft`，不提供无人值守远程 CAD 服务。
- 不承诺所有 FeatureWorks 结果等价于人工重建；不安全结果必须降级。

## 关键约束与依赖

- Windows x64、.NET 8、OneHistory.AppShell.Core 3.0.3。
- Solid Edge 2020 COM、SolidWorks 2025 SP5 COM 和 FeatureWorks。
- 通过 COM 注册和运行时探测定位厂商组件，不硬编码安装目录。
- 源 CAD 只读，不关闭启动前已存在的用户 CAD 进程。
- FeatureWorks 识别档依赖已人工激活的 SolidWorks 会话；失败必须报告并安全降级。

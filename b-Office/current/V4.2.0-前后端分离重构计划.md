# HistoryMinerva 4.2.0 前后端分离重构

## 版本目标

对 4.1.0 合并完成的 HistoryMinerva 项目做破坏性重构：Mapping（SE2SW）与 SWuse
两个模块合并为**单一模块**，纯前端 + 纯后端分离：

- **单模块单指令域**：对外模块名 `HistoryMinerva`，指令域统一 `historyminerva`；
  旧 `mapping.*` / `swuse.*` 不提供兼容别名（沿用 V4.0.0 改名不留别名的先例）。
- **前端**：`HistoryMinerva.dll` 承载原 Mapping 中央停靠页（窗口 ID/标题随模块改名），
  页面功能与交互不变；SWuse 独立窗口（`SWuseWindow`/`SWuseWindowHost`）删除——
  界面打磨方向未定，建模能力先保留在协议层。
- **后端**：所有操作代码集中于单一 `HistoryMinerva.Worker.exe`（x64 STA），
  入口按参数形态路由两条既有协议：

| 协议 | 参数形态 | 处理链 |
| --- | --- | --- |
| SE2SW 转换 | `<verb> <json> --cancel <signal>`（4 参数） | Solid Edge 导出 / SolidWorks 导入、识别、装配 |
| SWuse 构建 | `--request <json>`（2 参数） | Roslyn 编译 + SolidWorks 零件构建 |

协议 JSON、进度事件、退出码语义不变。`SWuse.Api` 保留为用户代码编译引用。
- **发布**：单清单 `z-HistoryMinerva/module.manifest.json`，包目录 `z-Package-HistoryMinerva`；
  部署脚本安装双槽（`AppShell/Modules/HistoryMinerva` + `service/Modules/HistoryMinerva`）
  并退役全部旧槽（`Mapping`、`SWuse`、OneHistoryStudio 的 `SE2SW`/`SWuse`）。
- **测试**：`b-Code-HistoryMinerva-Tests` 一处归拢——Smoke 合并 SE2SW 与 SWuse 全部用例，
  UiSmoke 保留页面截图，13 个 CAD 探针 + `SWuse.CadGate` 并入 `tools/`。

## 破坏性变更清单

| 项 | 旧 | 新 |
| --- | --- | --- |
| 模块名 / 槽位 | `Mapping`、`SWuse` 双模块 | `HistoryMinerva` 单模块 |
| 指令域 | `mapping.*`、`swuse.*` | `historyminerva.*`（convert/cancel + show/hide/status） |
| 窗口 ID / 标题 | `mapping` / Mapping | `historyminerva` / HistoryMinerva |
| Worker | `SE2SW.Worker.exe` + `SWuse.Worker.exe` | `HistoryMinerva.Worker.exe`（内部路由） |
| 数据目录 | `%AppData%/AppShell/Mapping`、`%LocalAppData%/OneHistoryStudio/SWuse` | `%AppData%/AppShell/HistoryMinerva`、`%LocalAppData%/HistoryMinerva/HistoryMinerva` |
| 版本线 | Mapping 4.1.0 / SWuse 0.1.1 双轨 | HistoryMinerva 4.2.0 单轨 |
| 源码目录 | `b-Code-SE2SW`、`b-Code-SWuse`、`b-Code-SE2SW-Tests` | `b-Code-HistoryMinerva`、`b-Code-HistoryMinerva-Tests` |
| SWuse UI | 独立顶层窗口 + `swuse.show/hide/status` | 窗口删除；占位指令如实说明现状 |

## 保留不变

- Mapping 页面全部功能、装配转换管线、FeatureWorks 识别守卫、配合重建；
- SWuse 建模 API（`PartBuilder`/`PartProgram`/`[SwuseEntry]`）、Roslyn dry-run 编译链、
  工作区文件规则（`SWuseWorkspace` 内部类）；
- 两条 Worker 协议的 JSON 形态与进程模型（独立 x64 STA、取消信号文件、stdout 进度）；
- AppShell 3.1.9 钉定快照校验（清单 + Core 哈希，哈希随宿主包重生成重钉）。

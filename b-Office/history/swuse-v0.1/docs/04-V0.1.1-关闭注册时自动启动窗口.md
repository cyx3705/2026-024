# SWuse V0.1.1：关闭注册时自动启动窗口

SWuse 仍保留独立顶层窗口和 `swuse.show`、`swuse.hide`、`swuse.status` 指令，但模块注册
生命周期不再自动创建或显示窗口。

## 行为

- `CreateUi()` 只完成生命周期接入，不调用窗口创建。
- 用户显式执行 `swuse.show` 时才创建并显示 SWuse 窗口。
- `swuse.status` 在未显式打开前返回“窗口尚未创建”。
- `DestroyUi()` 继续关闭已创建窗口，不改变 Worker 的清理逻辑。

## 验收

- 模块加载后无 SWuse 窗口自动出现。
- 独立窗口仍可通过 `swuse.show` 创建。
- AppShell 注入时不注册停靠工具窗口。
- Release build 与 `SWuse.Smoke` 通过。

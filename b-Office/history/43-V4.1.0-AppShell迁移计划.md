# Mapping 4.1.0 AppShell 3.1.9 迁移

Mapping 4.1.0 将现有 SE2SW 内部实现接入 AppShell 3.1.9 正式宿主快照。对外模块、窗口和指令域保持
`Mapping` / `mapping`；SE2SW 程序集、Worker 可执行文件和 JSON 协议不改名。

## 宿主合同

- `AppShell.Core.dll` 直接引用 `2026-023-AppShell/z-Package-AppShell/host/AppShell.Core.dll`，版本为
  `3.1.9.0`，生产引用 `Private=false`。
- 模块 UI 实现 `IModuleContextAware`、`IShellUiAware` 和 `IUiModule`，在 `DockSide.Center` 注册单例中央页。
- `mapping.convert` 与 `mapping.cancel` 是前端写命令，要求 UI 线程且 `AllowMcpExecution=false`；宿主服务发布的
  前端代理才使用 `ExecutionSite=Frontend`。只读 Mapping 查询继续由模块公共类提供。
- Worker 请求、探查结果和运行数据使用 `IModuleContext.DataDirectory` 下的 `Mapping/`；Worker 定位优先当前部署槽。

## 发布合同

`b-Code-SE2SW/eng/Build-MappingPackage.ps1` 校验 AppShell 快照版本与哈希，生成 `z-Package-Mapping`。
正式包包含七个 SE2SW 运行产物、`module.manifest.json`、AppShell 快照元数据和 `SHA256SUMS`，不包含任何
AppShell DLL。`Deploy-Mapping.ps1` 默认只预览，只有 `-Apply` 才会在 AppShell 完全关闭后部署双槽。

部署目标为 `%AppData%/AppShell/Modules/Mapping` 与 `%AppData%/AppShell/service/Modules/Mapping`；备份位于
Modules 目录外。两个槽验证一致后，旧 `%AppData%/OneHistoryStudio/Modules/SE2SW` 移入旧宿主备份区并退役。

## 验证边界

Release、协议 Smoke、UI Smoke、格式和 AIReady 合同属于每次发布门禁。UI Smoke 使用 AppShell 浅/深主题，
覆盖 320、760、1200px 宽度。4.1.0 不重复运行真实 CAD 门禁，继续使用既有 Worker/COM 真机证据。

# SE2SW V3.8.0 指令总线更新

## 目标

SE2SW 3.8.0 将模块公共入口注册到 OneHistoryStudio / AppShell 的 `CommandRegistry` 与 `CommandBus`。模块清单声明 `mcpExposure=readonly`，因此命令行和 MCP 客户端可以发现并调用安全的只读查询。

## 指令

| 指令 | 参数 | 行为 |
| --- | --- | --- |
| `se2sw.show` | 无 | 保留的 UI 显示兼容入口 |
| `se2sw.hide` | 无 | 保留的 UI 隐藏兼容入口 |
| `se2sw.status` | 无 | 返回版本、窗口 ID、Worker 路径/存在状态、Solid Edge/SolidWorks COM 注册状态、支持的输入和输出目录 |
| `se2sw.paths` | `source`、可选 `xt`、可选 `sw` | 解析单个 `.par` 的 XT/SW 输出路径，不创建目录 |
| `se2sw.scan` | `source`、可选 `xt`、可选 `sw` | 扫描目录顶层 `.par`，返回输出路径和已有产物状态，不创建目录 |

`status`、`paths`、`scan` 返回对象结果；AppShell 会将对象序列化为 `CommandResult.Data`，命令行同时显示可读文本和结构化数据。

## 安全边界

- 五条入口均标记为只读命令；3.8.0 不向命令行或 MCP 暴露真实 CAD 转换。
- `paths` 与 `scan` 不创建 XT/SW 目录，不写入源 CAD 或输出文件。
- Solid Edge、SolidWorks、FeatureWorks COM 自动化继续只在独立 Worker 和本机 UI 流程中执行。
- 保持 Worker JSON 协议、COM 行为、窗口 ID、命令 ID 和输出目录规则不变。

## 验证

完成 Release 构建、`SE2SW.Smoke`、AIReady 严格合同、`command.list domain=se2sw` 和 OHS `tool.sync name=SE2SW` 后，核验 `module.list` 为 `se2sw 3.8.0`，并调用三条只读查询确认结构化响应。

# Mapping 4.0.0 通用界面更新

## 版本目标

将面向 Solid Edge 到 SolidWorks 的既有 SE2SW 工具升级为通用文件映射入口。对外模块名、窗口 ID、
命令域和 MCP 前缀统一改为 `Mapping` / `mapping`；内部程序集、Worker 和 JSON 协议继续使用 SE2SW，
本版本不改变 CAD COM 转换行为。

## 用户界面

- 顶部由来源、XT、SW 三栏收敛为两个等宽栏：`转换来源` 与 `转换内容`。
- XT 与 SW 输出目录不再由用户配置，继续作为内部受控管线使用。
- 当前映射仅包含 Solid Edge `.par` 到 SolidWorks `.SLDPRT`，以及 Solid Edge `.asm` 到
  SolidWorks `.SLDASM`。
- 零件映射选择包含顶层 `.par` 的文件夹并显示全宽零件表；装配映射选择单个 `.asm`，探查后显示
  装配树和零件表。

## 公共接口

- OHS 模块清单：`name=Mapping`、`version=4.0.0`、`mcpExposure=readonly`、`ui=true`。
- 模块和窗口 ID：`mapping`；窗口标题：`Mapping`。
- 只读命令改为 `mapping.show/hide/status/paths/scan/assemblyPaths/assemblyProbe`。
- 旧 `SE2SW` 模块槽和 `se2sw.*` 指令不提供兼容别名。

## 验证边界

Release 构建、协议 Smoke、UI Smoke、格式和 AIReady 严格合同必须通过。此次改名和界面收敛不改动
Worker 协议或 CAD COM 实现，因此不重复运行真实 CAD 门禁，沿用最近的受控样件验收证据。
